⚙️ How it works
1
Assembly — Multiple GPT-4 AI personas debate your problem and converge on a product spec with MVP features, target user, and differentiator.
2
Spec Review — You review and optionally edit the spec before approving. Auto-approve skips this step.
3
Claude Code — Claude Code receives the spec as a prompt and builds the product, streaming every tool call, file write, and bash command live.
4
Review — Three reviewer personas (QA Engineer, Spec Checker, Integration Tester) independently judge the build and return pass / iterate / human_needed.
5
Iterate — If 2+ reviewers pass, the pipeline completes. Otherwise reviewer notes are fed back to Claude for another build attempt (max 2 iterations).
6
Human escalation — If reviewers can't agree or the iteration limit is hit, you're notified and can provide guidance to unblock the pipeline.
